# 卖家侧功能

当前 GUI 已接入 `goofish-cli` 的卖家侧能力：

- 客服工作台：会话列表、聊天记录、人工确认发送文本消息。
- 商品上架：填写标题、描述、价格、图片路径，调用 `item publish` 发布。

账号来源：

1. 优先使用 GUI 账号管理里的账号 JSON。
2. 账号 JSON 会自动转换成 `goofish-cli` 支持的 cookie 文件，缓存到
   `data/goofish-cookies/`。
3. 如果页面选择“自动读取 goofish-cli 登录态”，则使用 `goofish-cli` 自己的默认登录态。

写操作说明：

- 发送消息和发布商品都是真实账号写操作。
- 建议先用小号测试，并保持人工确认。
- 后续可以在客服工作台上继续加自动回复规则、AI 草稿、发送前风控词检查。
